# openstw

A project aiming to design a replica of a German Sp Dr S60 relais signal box panel.

## Repository structure
 - `hardware`: Contains design files for the various PCBs and 3d-printed components used in the project
 - `software`: The software that simulates the signal box, including simulated time tables and train traffic
 - `firmware`: Firmware for PCBs that need to be programmed
